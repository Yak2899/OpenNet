# OpnNet
The Internet 2.0, today’s internet is full of corporate and government control. OpenNet will change that forever.

In our current timeline the corrupted corporates and the governments have ruined the internet making it an insecure fish bowl with privacy violations, content control, censorship, footprint tracking and many more to mention.

Everything will be built from the ground up. This hopefully will be the beginning of a great internet revolution.

This project won’t be easy to achieve, but it’s possible with great community, time and people support. All contributions will be appreciated.
